# resume-builder

A web-based resume builder application built with React — generate professional resumes with customizable sections.

## Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5 / CSS3
- Node.js (backend)
- Create React App

## Features

- Create and customize resume sections (experience, education, skills)
- Live preview of resume as you type
- Export-ready professional layout
- Responsive design
- Full-stack architecture with React frontend and Node.js backend

## Getting Started

```bash
git clone https://github.com/chandurao77/resume-builder.git
cd resume-builder
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
